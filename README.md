# Simulador de Fila de Atendimento em Python

Projeto desenvolvido durante meus estudos de Python para entender na prática o funcionamento de uma fila de atendimento seguindo a lógica FIFO (First In, First Out).

O programa simula a chegada de solicitações de clientes, organiza essas requisições em uma fila e realiza o atendimento na mesma ordem em que elas chegaram.

## Funcionalidades

- Geração de requisições simuladas
- Registro de cliente, problema e horário de chegada
- Inclusão de novas requisições na fila
- Processamento das solicitações em ordem FIFO
- Exibição das requisições que ainda aguardam atendimento

## Conceitos aplicados

- Python
- Estruturas de dados
- FIFO (First In, First Out)
- `deque` da biblioteca `collections`
- Funções
- Listas e dicionários
- Manipulação de horário com `time`
